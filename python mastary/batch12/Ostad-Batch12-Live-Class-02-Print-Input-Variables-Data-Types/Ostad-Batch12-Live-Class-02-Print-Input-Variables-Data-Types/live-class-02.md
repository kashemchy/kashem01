## Introduction

গত ক্লাসে আমাদের প্রোগ্রামটা শুধু **বলেছে**। `print("Hello, World!")` - কম্পিউটার একটা লাইন ছেপে দিয়েছে, ব্যস।

কিন্তু একটা প্রোগ্রাম যদি সবসময় একই জিনিস ছাপে, সেটাকে প্রোগ্রাম না বলে **ছবি** বলা যেত। আসল প্রোগ্রামের পার্থক্য একটাই - সে **প্রতিবার আলাদা উত্তর দিতে পারে**, কারণ প্রতিবার তাকে আলাদা তথ্য দেওয়া হয়।

ভাবুন একটা দোকানের ক্যাশ মেমো। দোকানদার প্রতিবার নতুন সফটওয়্যার লেখেন না - **একই প্রোগ্রামে নতুন তথ্য** ঢোকান: কোন পণ্য, কত দাম, কয়টা। প্রোগ্রামটা সেই তথ্য নিয়ে হিসাব করে বিল ছাপে।

আজ আমরা ঠিক সেই তিনটে জিনিস শিখব, আর এই তিনটেই পরের ৪০টা ক্লাসের ভিত্তি:

| ধাপ | কাজ | আজকের হাতিয়ার |
|---|---|---|
| **INPUT** | তথ্য নাও | `input()` |
| **PROCESS** | রাখো ও হিসাব করো | variable, `int()`, `float()`, operator |
| **OUTPUT** | ফলাফল দেখাও | `print()`, f-string |

আজকের সবচেয়ে গুরুত্বপূর্ণ একটা বাক্য - এটা এখনই লিখে রাখুন, কারণ আজকের চারটে error-এর তিনটেই এখান থেকে আসে:

> **`input()` যা-ই ফেরত দিক, সেটা সবসময় text। ব্যবহারকারী `25` টাইপ করলেও Python সেটা `"25"` হিসেবেই রাখে - সংখ্যা হিসেবে নয়।**

## Concept 1: `print()` - পুরোটা

### সংজ্ঞা

`print()` হলো Python-এর সাথে **আগে থেকেই তৈরি করা** একটা নির্দেশ, যার কাজ একটাই - বন্ধনীর ভিতরে যা দেবেন, সেটা স্ক্রিনে দেখানো।

গত ক্লাসে আমরা একটা জিনিস দিয়েছি। আজ দেখব **একাধিক জিনিস** দিলে কী হয়, আর সেই জিনিসগুলোর মাঝখানে ও শেষে কী বসবে তা কীভাবে নিয়ন্ত্রণ করা যায়।

### তিনটে জিনিস, এটুকুই

| যা লিখবেন | Python কী করে | ডিফল্ট |
|---|---|---|
| `print(a, b)` | দুটোর মাঝে একটা **স্পেস** বসায় | স্পেস |
| `print(a, b, sep="-")` | মাঝখানে যা বলবেন তা বসায় | `" "` |
| `print(a, end="")` | লাইন শেষে যা বলবেন তা বসায় | `"\n"` (নতুন লাইন) |

`sep` এসেছে **sep**arator থেকে - "মাঝখানে কী"। `end` মানে "শেষে কী"।

### কোড - `print()`-এর দৈনন্দিন ৮০%

```python
# ----- 2) Many values in one print() - comma adds a space for you -----
print("My name is", "Rahim")
print("I am", 25, "years old")

# ----- 4) sep= decides what goes BETWEEN the values -----
print("2026", "08", "20", sep="-")
print("rahim", "gmail.com", sep="@")

# ----- 5) end= decides what comes AFTER the line -----
print("Loading", end="")
print(".", end="")
print(".", end="")
print(".")
```

##### Output

```
My name is Rahim
I am 25 years old
2026-08-20
rahim@gmail.com
Loading...
```

**পুরো ফাইল:** `examples/example_01_print_basics.py`

### খেয়াল করার মতো তিনটে জিনিস

1. **কমা নিজে থেকেই একটা স্পেস দেয়।** তাই `print("Total:", 100)` লিখলে `Total: 100` আসে - কোলনের পরে নিজে স্পেস দিতে হয় না। দুবার স্পেস দিলে দুটো স্পেসই দেখা যাবে।
2. **`"25"` আর `25` এক জিনিস নয়।** কোট থাকলে সেটা লেখা, না থাকলে সংখ্যা। স্ক্রিনে দুটোই একইরকম দেখায় - এই কারণেই আজকের অর্ধেক বিভ্রান্তি।
3. **`print()` ফাঁকা রাখলে শুধু একটা খালি লাইন পড়ে।** আউটপুট সাজানোর সবচেয়ে সহজ উপায়।

## Concept 2: `input()` - প্রোগ্রাম এবার প্রশ্ন করবে

### সংজ্ঞা

`input()` হলো `print()`-এর উল্টো নির্দেশ। `print()` দেখায়, `input()` **শোনে**।

`input()` ঠিক তিনটে কাজ করে, সবসময় এই ক্রমে:

1. বন্ধনীর ভিতরের লেখাটা স্ক্রিনে দেখায় (একে বলে **prompt**)
2. **থেমে যায়** - ব্যবহারকারী কিছু টাইপ করে Enter না চাপা পর্যন্ত অপেক্ষা করে
3. যা টাইপ করা হয়েছে সেটা **ফেরত দেয়**, যাতে আপনি variable-এ রাখতে পারেন

```python
name = input("What is your name? ")
```

এই এক লাইনে দুটো জিনিস ঘটছে - ডান দিক আগে চলে (প্রশ্ন করে, উত্তর নেয়), তারপর সেই উত্তরটা `name` নামে রাখা হয়।

> **Prompt-এর শেষে একটা স্পেস দিন** - `input("What is your name? ")`। না দিলে ব্যবহারকারীর টাইপ করা লেখা প্রশ্নচিহ্নের গায়ে লেগে যায়। ছোট জিনিস, কিন্তু প্রথম দিনেই অভ্যাস করে ফেলা ভালো।

### আজকের সবচেয়ে গুরুত্বপূর্ণ কথাটা

**`input()` সবসময় `str` ফেরত দেয়।** ব্যবহারকারী `25` লিখলেও Python সেটাকে `"25"` হিসেবে রাখে।

কেন? কারণ কীবোর্ড থেকে যা আসে তা তো অক্ষরের সারি - Python জানে না আপনি ওটাকে সংখ্যা হিসেবে চান, নাকি রোল নম্বর, নাকি মোবাইল নম্বর হিসেবে (`01730709253` কে সংখ্যা বানালে সামনের শূন্যটা হারিয়ে যেত!)। তাই সে **সিদ্ধান্তটা আপনার হাতে ছেড়ে দেয়**।

### কোড - এবং সেই বিখ্যাত বিস্ময়

```python
# ----- 3) Ask for something that LOOKS like a number -----
age_text = input("How old are you? ")
print("You typed:", age_text)

# ----- 4) Proof that it is text, not a number -----
print("The type of what you typed is:", type(age_text))

# ----- 5) The surprise this causes -----
print("age_text + age_text =", age_text + age_text)
```

##### Output (ব্যবহারকারী `25` টাইপ করলে)

```
How old are you? 25
You typed: 25
The type of what you typed is: <class 'str'>
age_text + age_text = 2525
```

**পুরো ফাইল:** `examples/example_02_input_basics.py`

### `2525` কেন?

কারণ **text-এর জন্য `+` মানে যোগ নয়, জোড়া লাগানো**। `"25" + "25"` মানে "এই লেখাটার পিছনে ওই লেখাটা লাগাও" - ফল `"2525"`। Python কোনো error দেয়নি, কারণ কাজটা সম্পূর্ণ বৈধ। সে শুধু আপনি যা চেয়েছেন তা-ই করেছে।

**এটাই আজকের আসল শিক্ষা:** কম্পিউটার আপনার ভুল ধরে না, সে আপনার ভুলটা নিখুঁতভাবে পালন করে। ঠিক করার উপায় Concept 4-এ - `int()`।

## Concept 3: Variable ও চারটে Data Type

### ভুল ছবিটা আগে ভাঙি

বেশিরভাগ বই বলে - "variable হলো একটা বাক্স, তার ভিতরে মান রাখা থাকে।" ছবিটা সহজ, কিন্তু **ভুল**, আর এই ভুল ছবির কারণেই পরে list ও dictionary-তে গিয়ে মানুষ আটকে যায়।

**সঠিক ছবি:** মানটা মেমরিতে কোথাও একটা পড়ে আছে। Variable হলো সেই মানের গায়ে বাঁধা একটা **নাম-ট্যাগ**।

```
age = 25
```

মানে: "মেমরিতে যে 25 আছে, তার গায়ে age নামের ট্যাগটা বেঁধে দাও।"

> **`=` চিহ্নটা অঙ্কের সমান নয়।** পড়ুন **"পাচ্ছে"** হিসেবে। `age = 25` মানে "age পাচ্ছে 25"। তাই `age = age + 1` লাইনটাও পুরোপুরি বৈধ - অঙ্কে যেটা অসম্ভব।

### চারটে দৈনন্দিন Data Type

| Type | মানে | উদাহরণ | কীভাবে চিনবেন |
|---|---|---|---|
| `int` | পূর্ণ সংখ্যা | `25`, `0`, `-7` | কোট নেই, দশমিক নেই |
| `float` | দশমিক সংখ্যা | `99.5`, `3.14`, `9.0` | দশমিক বিন্দু আছে |
| `str` | লেখা | `"Rahim"`, `"25"` | কোটের ভিতরে |
| `bool` | সত্য/মিথ্যা | `True`, `False` | বড় হাতের T আর F |

> **`True` আর `False`-এ প্রথম অক্ষর বড় হাতের** - `true` লিখলে Python চিনবে না, `NameError` দেবে। এটা Live Class 01-এর case sensitivity নিয়মেরই ধারাবাহিকতা।

### নামকরণের নিয়ম - Python যা মানে

| চলবে | চলবে না | কারণ |
|---|---|---|
| `age`, `total_marks`, `x1` | `1x`, `2nd_name` | সংখ্যা দিয়ে শুরু করা যায় না |
| `monthly_salary` | `monthly salary` | নামে স্পেস চলে না |
| `first_name` | `first-name` | ড্যাশকে Python বিয়োগ ভাবে |
| `my_print` | `print`, `input`, `type` | Python-এর নিজের নাম দখল করবেন না |

**Convention (নিয়ম নয়, ভদ্রতা):** ছোট হাতের অক্ষর, শব্দের মাঝে আন্ডারস্কোর - একে বলে **snake_case**। `monthly_salary` লিখুন, `MonthlySalary` বা `ms` নয়।

**সবচেয়ে দরকারি পরামর্শ:** নাম দেখেই যেন বোঝা যায় ভিতরে কী আছে। `x = 50000` লিখলে আগামী সপ্তাহে আপনি নিজেই বুঝবেন না ওটা বেতন না দাম না দূরত্ব।

### কোড

```python
# ----- 1) One variable of each type -----
name = "Rahim Uddin"        # str   - quotes make it text
age = 25                    # int   - whole number, no quotes
height = 5.6                # float - has a decimal point
is_student = True           # bool  - True or False, capital letter

# ----- 3) type() tells you what kind of value a name is pointing to -----
print("type(name)       =", type(name))
print("type(age)        =", type(age))
print("type(height)     =", type(height))
print("type(is_student) =", type(is_student))
```

##### Output

```
type(name)       = <class 'str'>
type(age)        = <class 'int'>
type(height)     = <class 'float'>
type(is_student) = <class 'bool'>
```

**পুরো ফাইল:** `examples/example_03_variables_and_types.py`

`<class 'int'>` লেখাটা দেখতে ভয়ংকর, কিন্তু পড়ুন এভাবে - **"এটা int জাতের জিনিস"**। `class` শব্দটা নিয়ে আজ ভাববেন না, ওটা Module 13-এর কাজ।

## Concept 4: Type Conversion, `type()` ও `id()`

### ৪.১ Type Conversion - সমস্যাটার সমাধান

`input()` text দেয়, কিন্তু আপনার দরকার সংখ্যা। মাঝখানের সেতুটার নাম **type conversion** (বা casting)। তিনটে নির্দেশ, এটুকুই:

| নির্দেশ | কাজ | উদাহরণ |
|---|---|---|
| `int(x)` | পূর্ণ সংখ্যায় বদলায় | `int("25")` = `25` |
| `float(x)` | দশমিক সংখ্যায় বদলায় | `float("99.5")` = `99.5` |
| `str(x)` | লেখায় বদলায় | `str(100)` = `"100"` |

```python
# ----- 1) The core problem, without any input() in the way -----
age_text = "25"                     # pretend this came from input()
print("age_text + age_text =", age_text + age_text)      # joining, not adding

# ----- 2) The fix: convert once, then use the number -----
age = int(age_text)
print("age + age       =", age + age)                    # real addition
```

##### Output

```
age_text + age_text = 2525
age + age       = 50
```

**পুরো ফাইল:** `examples/example_04_type_conversion.py`

### ৪.২ কখন conversion ব্যর্থ হয়

`int()` কড়া। সে শুধু **পরিষ্কার পূর্ণ সংখ্যা** আছে এমন লেখাই বদলাতে পারে।

| যা লিখবেন | ফল |
|---|---|
| `int("25")` | চলবে - `25` |
| `int(" 25 ")` | চলবে - আশেপাশের স্পেস উপেক্ষা করে |
| `int("25 years")` | **ValueError** - ভিতরে শব্দ আছে |
| `int("9.5")` | **ValueError** - এটা float, int নয় |
| `int(9.99)` | চলবে - `9`, কিন্তু **round করে না, দশমিকটা ফেলে দেয়** |

শেষ সারিটা মনে রাখুন - **`int(9.99)` মানে `10` নয়, `9`।** এটা কেটে ফেলা, গোল করা নয়।

`"9.5"` কে সংখ্যা বানাতে হলে দুবার বদলান - `int(float("9.5"))` = `9`।

### ৪.৩ `id()` - reassignment আসলে কী করে

`id(x)` একটা লম্বা সংখ্যা দেয়, মেমরিতে মানটার ঠিকানার মতো। **বাস্তব প্রোগ্রামে আপনি `id()` কখনো ব্যবহার করবেন না।** এটা আজ শুধু এই জন্য যে, নাম-ট্যাগের ছবিটা সত্যি - সেটা চোখে দেখা যায়।

```python
# ----- 1) A name tied to a value -----
city = "Dhaka"
print("city =", city, " id =", id(city))

# ----- 2) Reassignment moves the TAG, it does not edit the value -----
city = "Chattogram"
print("city =", city, " id =", id(city), " <- a different id")

# ----- 5) Numbers are immutable: maths builds a NEW value -----
counter = 5
print("counter =", counter, " id =", id(counter))
counter = counter + 1
print("counter =", counter, " id =", id(counter), " <- new value, new id")
```

##### Output (আপনার মেশিনে সংখ্যাগুলো আলাদা হবে - সেটাই স্বাভাবিক)

```
city = Dhaka  id = 2341117972896
city = Chattogram  id = 2341117986416  <- a different id
counter = 5  id = 140717523322104
counter = 6  id = 140717523322136  <- new value, new id
```

**পুরো ফাইল:** `examples/example_05_id_and_memory.py`

**যা প্রমাণ হলো:** `city` বদলানোর সময় `"Dhaka"` লেখাটা এডিট হয়নি - ট্যাগটা অন্য একটা মানের গায়ে গিয়ে বসেছে। একইভাবে `counter + 1` একটা **নতুন** `6` বানিয়েছে, পুরনো `5` কে বদলায়নি।

> **`id()` নিয়ে দুশ্চিন্তা করবেন না।** পরীক্ষায় id-র সংখ্যা মুখস্থ করতে হবে না। শুধু একটা বাক্য মনে রাখুন - **নাম বদলালে ট্যাগ সরে, মান বদলায় না।**

## Concept 5: Expression লেখা

### সংজ্ঞা

**Expression** = এমন যেকোনো কিছু, যা Python হিসাব করে **একটা মানে** নামিয়ে আনতে পারে।

* `500 * 3` = `1500`
* `price * quantity` = `1500`
* `total > 1000` = `True`

সহজ পার্থক্য - **statement কিছু করে, expression-এর একটা মান থাকে।**

### সাতটা Arithmetic Operator

| Operator | কাজ | `7` ও `2` দিয়ে | ফল |
|---|---|---|---|
| `+` | যোগ | `7 + 2` | `9` |
| `-` | বিয়োগ | `7 - 2` | `5` |
| `*` | গুণ | `7 * 2` | `14` |
| `/` | ভাগ | `7 / 2` | `3.5` |
| `//` | পূর্ণ ভাগ | `7 // 2` | `3` |
| `%` | ভাগশেষ | `7 % 2` | `1` |
| `**` | ঘাত | `7 ** 2` | `49` |

**দুটো জিনিস অবাক করে:**

1. **`/` সবসময় `float` দেয়** - এমনকি নিঃশেষে ভাগ গেলেও। `10 / 2` মানে `5.0`, `5` নয়। পূর্ণ সংখ্যা চাইলে `//` ব্যবহার করুন।
2. **`%` (ভাগশেষ) খুব কাজের** - `n % 2` দিয়ে জোড়-বিজোড় বোঝা যায়।

### কোনটা আগে হিসাব হয়

`**` আগে, তারপর `*` `/` `//` `%`, শেষে `+` `-`; সমান হলে বাঁ থেকে ডানে।

```
2 + 3 * 4     =  14      (গুণ আগে)
(2 + 3) * 4   =  20      (বন্ধনী সবার আগে)
```

> **নিয়ম মুখস্থ করার চেয়ে বন্ধনী দিন।** বন্ধনী দিতে কোনো খরচ নেই, আর পরে যে কোডটা পড়বে (প্রায়ই আপনি নিজেই) সে ধন্যবাদ দেবে।

### তুলনার Operator - ফল সবসময় `bool`

`>` `<` `>=` `<=` `==` `!=` - প্রতিটার ফল `True` বা `False`।

> **`=` আর `==` এক জিনিস নয়।** `=` মান বসায়, `==` মিলিয়ে দেখে। এটাই সবচেয়ে বেশি হওয়া দ্বিতীয় দিনের ভুল। পড়ার সময় বলুন - "এক সমান মানে রাখো, দুই সমান মানে মেলাও"।

### f-string - ফলাফল সাজানোর আধুনিক উপায়

কোটের আগে একটা `f` বসান, তারপর `{ }`-এর ভিতরে যেকোনো variable বা expression লিখুন।

```python
# ----- 6) f-string: putting values inside a sentence -----
product = "Laptop"
print(f"{product} x {quantity} = {total} taka")

# ----- 7) Two f-string tricks worth knowing today -----
vat = total * 0.15
print(f"VAT       : {vat:.2f}")
print(f"Big number: {1234567:,}")
```

##### Output

```
Laptop x 3 = 1500 taka
VAT       : 225.00
Big number: 1,234,567
```

**পুরো ফাইল:** `examples/example_06_basic_expressions.py`

দুটো কাজের ট্রিক - **`:.2f`** মানে দশমিকের পরে ঠিক দুই ঘর (টাকা-পয়সার জন্য), আর **`:,`** মানে বড় সংখ্যায় কমা।

**`f` না লিখলে কী হয়?** `print("{product} taka")` লিখলে স্ক্রিনে হুবহু `{product} taka` ছাপবে। `{ }` জাদু নয় - `f`-টাই জাদু।

## আজকের চারটে Error - ইচ্ছা করে দেখা করে নিই

চারটের তিনটেই একই কারণে হয় - **`input()` text দেয়, আর text সংখ্যার মতো আচরণ করে না।**

**পুরো ফাইল:** `examples/example_07_input_math_wrong.py`

### ১. `TypeError` - রূপান্তর ছাড়াই হিসাব

```
age = input("Your age: ")     # ব্যবহারকারী টাইপ করল 25
print(age + 10)
```

```
TypeError: can only concatenate str (not "int") to str
```

**পড়ুন এভাবে:** "আপনি text-এর সাথে সংখ্যা জোড়া লাগাতে বলেছেন, আমি পারি না।" সমাধান অন্য `+` চিহ্ন নয় - `input()`-এর চারপাশে `int()`।

### ২. `ValueError` - ভিতরে শব্দ আছে

```
age = int("25 years")
```

```
ValueError: invalid literal for int() with base 10: '25 years'
```

**"invalid literal" মানে:** লেখাটা পরিষ্কার পূর্ণ সংখ্যা নয়। `int()` `"25"` বদলায়, কিন্তু `"25 years"`, `"25/-"` বা `"twenty five"` কখনোই নয়।

### ৩. `ValueError` - দশমিককে `int()` করা

```
price = int("99.5")
```

```
ValueError: invalid literal for int() with base 10: '99.5'
```

`"99.5"` পূর্ণ সংখ্যা নয়। দশমিক থাকলে `float()` ব্যবহার করুন; পূর্ণ সংখ্যা লাগলে দুবার বদলান - `int(float("99.5"))`।

### ৪. `NameError` - নামে টাইপো

```
total = 1500
print(totl)
```

```
NameError: name 'totl' is not defined. Did you mean: 'total'?
```

Python আন্দাজ করে না। variable-এর নামে একটা অক্ষর ভুল মানে সেটা সম্পূর্ণ নতুন, খালি একটা নাম। খেয়াল করুন - সে নিজেই সঠিক নামটা সাজেস্ট করছে।

### ৫. যেটা error দেয় না - আর সেটাই সবচেয়ে বিপজ্জনক

```
marks = input("Marks: ")   # ব্যবহারকারী টাইপ করল 50
print(marks * 3)           # ছাপে 505050, 150 নয়
```

Python কোনো অভিযোগ করে না, কারণ **লেখাকে তিনবার পুনরাবৃত্তি করা সম্পূর্ণ বৈধ কাজ**। প্রোগ্রাম চলে, উত্তর ভুল আসে। এই ধরনের bug ধরার একমাত্র উপায় - সন্দেহ হলেই `type()` দিয়ে দেখে নেওয়া।

## সব একসাথে - দোকানের ক্যাশ মেমো

আজকের সবকিছু এক প্রোগ্রামে। নতুন কিছু নেই - শুধু `input()`, variable, `int()`, `float()`, হিসাব আর `print()`।

**মনে রাখার তিনটে শব্দ - প্রায় প্রতিটা প্রোগ্রামের গঠন এটাই:**

| ধাপ | কাজ |
|---|---|
| **INPUT** | যা দরকার তা সংগ্রহ করো |
| **PROCESS** | রূপান্তর করে হিসাব করো |
| **OUTPUT** | ফল দেখাও |

```python
# ===== INPUT: collect what we need (everything arrives as text) =====
product = input("Product name    : ")
price_text = input("Unit price      : ")
quantity_text = input("How many pieces : ")

# ===== PROCESS: convert first, then calculate =====
price = float(price_text)          # a price can have a decimal -> float
quantity = int(quantity_text)      # a count is always whole     -> int

subtotal = price * quantity
vat = subtotal * 0.15              # 15% VAT
total = subtotal + vat

# ===== OUTPUT: show it like a real receipt =====
print(f"Subtotal  : {subtotal:.2f} taka")
print(f"VAT (15%) : {vat:.2f} taka")
print(f"TOTAL     : {total:.2f} taka")
```

##### Output (ব্যবহারকারী Laptop, 75500, 3 টাইপ করলে)

```
Product name    : Laptop
Unit price      : 75500
How many pieces : 3

==================================
            CASH MEMO
==================================
Product   : Laptop
Unit price: 75500.00 taka
Quantity  : 3
----------------------------------
Subtotal  : 226500.00 taka
VAT (15%) : 33975.00 taka
TOTAL     : 260475.00 taka
==================================
Thank you, come again.
```

**পুরো ফাইল:** `examples/example_08_shop_bill.py`

**তিনটে ধাপ আলাদা রাখুন।** সব `input()` উপরে, সব হিসাব মাঝখানে, সব `print()` নিচে - এই কারণেই ফাইলটা পড়া সহজ। তিনটে মিশিয়ে ফেলাই beginner কোড জটিল হওয়ার প্রধান কারণ।

## "যদি এটা করি তাহলে কী হয়?" - আগেই উত্তর

ক্লাসে এই প্রশ্নগুলো প্রতিবারই আসে। উত্তরগুলো এখানে লিখে রাখা হলো, যাতে আটকে গেলে খুঁজতে না হয়।

**প্রশ্ন: `input()` এ prompt না দিলে কী হয়?**
প্রোগ্রাম চলবে, কিন্তু স্ক্রিনে শুধু একটা কার্সর জ্বলবে - ব্যবহারকারী বুঝবে না কী চাওয়া হচ্ছে। error নয়, কিন্তু খারাপ প্রোগ্রাম।

**প্রশ্ন: `int(input())` না লিখে `input()` এর পর আলাদা লাইনে `int()` করলে সমস্যা আছে?**
কোনো সমস্যা নেই, দুটো একদম সমান। শুরুতে **দুই লাইনে লেখাই ভালো** - কোন ধাপে কী হচ্ছে চোখে দেখা যায়। এক লাইনে গুছিয়ে লেখা পরে অভ্যাস হয়ে যাবে।

**প্রশ্ন: `5 + 5` লিখলে `10`, কিন্তু `"5" + "5"` লিখলে `55` কেন?**
কারণ `+` চিহ্নটা দুই ধরনের কাজ করে - সংখ্যার জন্য যোগ, লেখার জন্য জোড়া লাগানো। Python বাঁ পাশের জিনিসটা দেখে সিদ্ধান্ত নেয়।

**প্রশ্ন: `"5" + 5` লিখলে?**
`TypeError`। এক পাশে লেখা আর অন্য পাশে সংখ্যা - Python আন্দাজ করতে রাজি নয় আপনি কোনটা চেয়েছেন।

**প্রশ্ন: `10 / 2` কেন `5.0`, `5` নয়?**
`/` সবসময় `float` দেয়, এটা Python 3-এর নিয়ম। পূর্ণ সংখ্যা চাইলে `//` বা `int(10 / 2)`।

**প্রশ্ন: variable-এর নাম বাংলায় দেওয়া যায়?**
কারিগরিভাবে যায় (`নাম = "রহিম"` চলে), কিন্তু **দেবেন না**। বাকি দুনিয়ার সব কোড, লাইব্রেরি আর error message ইংরেজিতে - মেশালে পড়া কঠিন হয়ে যায়।

**প্রশ্ন: `type()` আর `id()` কি পরীক্ষায় লাগবে?**
`type()` সারাজীবন কাজে লাগবে - bug খোঁজার প্রথম হাতিয়ার। `id()` আজকের পর আর প্রায় লাগবেই না; ওটা শুধু ধারণাটা চোখে দেখানোর জন্য।

**প্রশ্ন: `#` দিয়ে লেখা comment কি প্রোগ্রামকে ধীর করে?**
না। Python comment সম্পূর্ণ উপেক্ষা করে। comment লেখার খরচ শূন্য, কিন্তু লাভ অনেক।

**প্রশ্ন: একই variable-এ আগে সংখ্যা, পরে লেখা রাখা যায়?**
যায়, Python বাধা দেবে না। কিন্তু ভুল করে এটা ঘটলে পরে `TypeError` ধরা কঠিন হয়ে যায়। একটা variable একটা কাজেই রাখুন।

## ক্লাসে হাতে-কলমে - দুটো লেন

ব্যাচে সবার আগের অভিজ্ঞতা এক নয়। তাই প্রতিটা অনুশীলনে **দুটো লেন** থাকবে। নিজের লেনটা বেছে নিন - দুটোই ঠিক, কেউ পিছিয়ে নেই।

### লেন ক - সবার জন্য (বাধ্যতামূলক)

1. `print()` দিয়ে নিজের নাম, শহর আর বয়স তিন লাইনে ছাপান।
2. `print("2026", "08", "20", sep="/")` চালিয়ে দেখুন `sep` বদলালে কী হয়।
3. `input()` দিয়ে নাম চান, তারপর `print("Hello,", name)` দিয়ে ফিরিয়ে বলুন।
4. `input()` দিয়ে দুটো সংখ্যা নিন, `int()` করুন, যোগফল ছাপান।
5. `int()` না করে একই কাজ করুন - error টা নিজের চোখে দেখুন, তারপর ঠিক করুন।
6. চারটে variable বানান (`int`, `float`, `str`, `bool`) আর প্রতিটার `type()` ছাপান।

### লেন খ - আগে থেকে কিছু জানা থাকলে

1. `example_08_shop_bill.py`-তে একটা delivery charge যোগ করুন, আর VAT-এর হারটা উপরে একটা variable-এ তুলুন।
2. ব্যবহারকারীর কাছ থেকে সেকেন্ড নিয়ে সেটাকে `//` আর `%` দিয়ে "X মিনিট Y সেকেন্ড" আকারে ছাপান।
3. একটা তিন অঙ্কের সংখ্যা নিন, `//` আর `%` দিয়ে তার তিনটে অঙ্ক আলাদা করে ছাপান।
4. `:>10`, `:<10`, `:^10` - f-string-এর এই তিনটে দিয়ে একটা সাজানো টেবিল বানান।
5. `id()` দিয়ে দেখান যে `a = 256` আর `b = 256` একই object, কিন্তু `a = 1000` আর `b = 1000` নাও হতে পারে - কেন হতে পারে ভেবে দেখুন।

## Summary - আজকের সাতটা লাইন

1. `print()` একাধিক মান নেয়; কমা একটা স্পেস দেয়, `sep=` মাঝেরটা বদলায়, `end=` শেষেরটা।
2. `input()` prompt দেখায়, থামে, আর যা টাইপ হয়েছে তা ফেরত দেয় - **সবসময় `str` হিসেবে**।
3. Variable মানে বাক্স নয়, **নাম-ট্যাগ**; `=` মানে "পাচ্ছে", সমান নয়।
4. চারটে দৈনন্দিন type - `int`, `float`, `str`, `bool`; যাচাইয়ের হাতিয়ার `type()`।
5. হিসাবের আগে রূপান্তর - `int()`, `float()`, `str()`; `int()` কড়া, `int(9.99)` মানে `9`।
6. সাতটা operator - `+ - * / // % **`; `/` সবসময় float দেয়; বন্ধনী সবার আগে।
7. আজকের চারটে error-এর তিনটেই একই কারণে - **text কে সংখ্যা ভেবে ফেলা**।
